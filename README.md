# Server Mods

Client-side mods for `srv1964233.hstgr.cloud` (Minecraft 1.20.1, Forge).

## Setup

1. Install **Forge 1.20.1** (47.4.23) if you haven't already: https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html
2. Download all the `.jar` files in this repo (green **Code** button above → **Download ZIP**, or grab them one at a time).
3. Type `%appdata%` into the Windows search bar - easy way to find your `.minecraft` folder.
4. Put the zip file contents inside of the `mods` folder. If no `mods` folder exists, create one called "mods", no caps.
5. Launch the Forge 1.20.1 profile and join `srv1964233.hstgr.cloud`.

## What's included

- `claimguard-0.1.0.jar` - the custom server mod (claims, RPG stats, combat classes, magic, village housing)
- `DistantHorizons-*.jar` - extended render distance
- `embeddium-*.jar` - performance/FPS
- `oculus-*.jar` - shader support (works with embeddium)
- `xaerominimap-*.jar` - minimap

All mods must match the versions here exactly - mismatched versions between players (or with the server) can cause crashes or desyncs.
